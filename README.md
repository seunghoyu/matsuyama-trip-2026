# 마쓰야마, 우리 둘의 가을

2026.10.01–10.04 / 3박 4일 / 대중교통 / 바이신지·맛집·카페·쇼핑.

모바일 우선 정적 여행 일정 페이지입니다. 날짜별 추천 일정, 구간별 이동 안내, 현재 위치 및 이전 장소 출발 Google Maps 링크, 공식 출처를 제공합니다.

## 실행
빌드·설치가 필요하지 않습니다. 이 폴더에서 `python -m http.server 4173 --bind 127.0.0.1` 실행 후 http://127.0.0.1:4173 접속.

## 배포
GitHub Pages: `main` 브랜치 `/ (root)`에서 배포. 외부 API 키나 서버가 필요하지 않습니다. 모든 경로는 상대경로이므로 프로젝트 Pages 주소에서도 작동합니다.

## 내용 수정
- `app.js`: 날짜별 일정·경로·공식 출처
- `food.js`: 맛집·카페 목록, 지도 장소 좌표, 위치 요청·거리 정렬·필터
- `place-info.js`: 직접 확인한 Google Maps 영업시간·확인일·공식 정보 차이
- `index.html`: 항공편, 교통 가이드, 여행 메모
- `styles.css`: 모바일·데스크톱 반응형 스타일
- `ITINERARY.md`: 조사 근거와 계획

숙소는 미정이며 오카이도 주변을 임시 거점으로 설정했습니다. 경로 최적화 서버나 실시간 교통 API는 없습니다. 근접한 장소를 묶은 추천 동선과 Google Maps의 현행 경로 검색을 이용합니다. 여행 날짜·시간은 지도 앱에서 직접 선택합니다. 맛집 탭을 열면 브라우저 위치 권한을 요청합니다. 허용된 좌표는 현재 페이지 메모리에서 직선거리 정렬에만 사용하고 서버·분석도구로 전송하거나 저장하지 않습니다. 위치는 5분 뒤 탭 재방문 또는 수동 갱신 때 다시 확인합니다. Google Maps 길찾기는 사용자가 버튼을 누른 뒤 Google에서 현재 위치를 확인하며 이 사이트는 좌표를 URL에 넣지 않습니다. 공동 편집·기기 간 상태 동기화 기능은 없습니다. 두 사람 모두 동일한 공개 URL로 일정을 봅니다.

정보 확인: 2026-09-22. 공항버스는 2026-10-01–24 공식 시간표 적용. 항공편은 제공된 예약 이미지에서 확인한 일정이며 원본 예약 이미지는 포함하지 않습니다. 임시휴무·교통·운항 변경은 방문 전 재확인이 필요합니다.

맛집은 별도 탭으로 분리했으며 일정은 점심·저녁·카페 시간만 표시합니다. 위치 허용 전/거절/시간 초과 시에는 등록 순서임을 명시하며 가까운 순서라고 표시하지 않습니다. 거리순은 직선거리 기준으로 실제 도보 최단 경로나 영업 중 순서가 아닙니다. 테스트: 저장소 외부 워크스페이스의 `test-food.cjs`에서 위치 성공·거절·시간 초과·재시도·종류 필터를 검증합니다.

지역 이야기 확장(2026-09-22): `stories.js`에 24개 소제목의 장문 한국어 해설을 관리합니다. 각 소제목에 공식 원문 링크를 연결하고 전설·지명설은 기록된 역사와 구분합니다. 일정과 맛집은 `storyKeys`로 동일한 지역 해설을 사용합니다. 원문을 그대로 번역하지 않고 여행 동선에서 관찰할 거리와 함께 재서술했습니다.
