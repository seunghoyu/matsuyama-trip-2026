# 마쓰야마, 우리 둘의 가을

2026.10.01–10.04 / 3박 4일 / 대중교통 / 바이신지·맛집·카페·쇼핑.

모바일 우선 정적 여행 일정 페이지입니다. 날짜별 추천 일정, 구간별 이동 안내, 현재 위치 및 이전 장소 출발 Google Maps 링크, 공식 출처를 제공합니다.

## 실행
빌드·설치가 필요하지 않습니다. 이 폴더에서 `python -m http.server 4173 --bind 127.0.0.1` 실행 후 http://127.0.0.1:4173 접속.

## 배포
GitHub Pages: `main` 브랜치 `/ (root)`에서 배포. 외부 API 키나 서버가 필요하지 않습니다. 모든 경로는 상대경로이므로 프로젝트 Pages 주소에서도 작동합니다.

## 내용 수정
- `app.js`: 날짜별 일정·경로·공식 출처
- `place-info.js`: 직접 확인한 Google Maps 영업시간·확인일·공식 정보 차이
- `index.html`: 항공편, 교통 가이드, 여행 메모
- `styles.css`: 모바일·데스크톱 반응형 스타일
- `ITINERARY.md`: 조사 근거와 계획

숙소는 미정이며 오카이도 주변을 임시 거점으로 설정했습니다. 경로 최적화 서버나 실시간 교통 API는 없습니다. 근접한 장소를 묶은 추천 동선과 Google Maps의 현행 경로 검색을 이용합니다. 여행 날짜·시간은 지도 앱에서 직접 선택합니다. 사용자의 위치를 이 사이트가 수집하거나 저장하지 않습니다. 공동 편집·기기 간 상태 동기화 기능은 없습니다. 두 사람 모두 동일한 공개 URL로 일정을 봅니다.

정보 확인: 2026-09-22. 공항버스는 2026-10-01–24 공식 시간표 적용. 항공편은 제공된 예약 이미지에서 확인한 일정이며 원본 예약 이미지는 포함하지 않습니다. 임시휴무·교통·운항 변경은 방문 전 재확인이 필요합니다.
